# Changelog

## \[2026.07.06]

* Novo: intervalo do loop agora é ajustável em tempo real com as teclas **A** (aumenta) e **D** (diminui), variando de 1,0 a 10,0 segundos, com padrão de **2,0 segundos**.
* Novo: ao ativar o loop (tecla **R** ou clique na caixa de seleção), o programa informa por voz que A/D ajustam o intervalo.
* Correção: em alguns casos, após tocar uma corda ou acorde único sem loop, a tecla **Esc** não fechava a janela na primeira tentativa (o programa entendia, erradamente, que ainda havia som tocando).
* Correção: se o complemento fosse desativado/recarregado com a janela do afinador aberta, ela podia ficar "órfã", com o timer continuando a rodar em segundo plano.
* Ajuste: reduzida a quantidade de informações faladas automaticamente ao abrir a janela (o intervalo do loop e o atalho de repetição agora só são anunciados quando o usuário interage com o loop).

## \[2026.05.02]

* Atualizada a compatibilidade para NVDA 2026.1



## \[2026.03.16] - Primeira versão pública

* Lançamento inicial do **Reference Tone-uner**, um complemento para o NVDA.
* Afinador de violão acessível para pessoas cegas.
* O programa reproduz o som de cada corda, permitindo que o usuário ajuste a afinação de ouvido.
